The query runs in a few milliseconds; the animation replays its traversal one step at a time so you can see which relationships it follows. Counts are relationships the in-browser engine actually read, not a benchmark of any graph database. Snowflake would remain the source of truth; a graph layer would sync a subset of it.
    
    
    
  
    

    

    
  
    
    
    
      
    
        
    Data model
    
        
    Seven node types and fifteen relationship types. Properties live on the relationships where they belong: a skill level sits on HAS_SKILL, a required level on REQUIRES, an expiry date on CERTIFIED. In production each of these would be synced from a Snowflake table.
